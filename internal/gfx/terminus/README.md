# Terminus Font

neonmux draws its interface (pane headers, status bar, palette, help) with
[Terminus Font](https://terminus-font.sourceforge.net/) 4.49.1 by Dimitar
Toshkov Zhekov. It is licensed under the SIL Open Font License 1.1, see
[OFL.TXT](OFL.TXT). The fonts in this directory stay under that license: the
MIT license of neonmux does not apply to them.

The `.bdf.gz` files are the original BDF files of the `terminus-font-4.49.1`
release, unchanged and compressed with `gzip -9 -n`. `gunzip` gives back the
exact files of the release. Only the Unicode (`ter-u*`) normal and bold
weights at 12 to 32 pixels are included.
